# Placement & Application Module

This project is a working student placement dashboard for managing placement drives, applications, eligibility checks, shortlisting, and review status.

## Features

- Create placement drives
- View active placements and KPI summaries
- Track students and applications
- Update application status through the pipeline
- Search student records
- Local browser storage persistence

## Run locally

From this folder:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```
